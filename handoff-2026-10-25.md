## How to run things here

- **Build.** Bump the version in the four files first. Then `npm run prod`, then `npm run build:chrome-dev`. The second one writes the dev primary's folder.
- **Load.** Run `node scratchpad/fresh-extensions-tab.js` (port 9222 is hard-coded), then `npm run reload:chrome-dev`. A reload clears the paused flag. Open the dashboard and pause right away. Then check recent flight-recorder events for tab opens.
- **Limit.** Send `resume-paused-coordinator-nukes` with `debugLimit: {minutes: 5, targets: 0}` from the dashboard page, using `send-extension-message-json.js --context page --file resume-5min.json`. Verify with `get-debug-resume-limit-status`. The limit does not survive a worker restart.
- **Flight recorder.** It keeps only the last 20,000 events, so long runs lose their start. Fetch it right after the run with `get-flight-recorder` and limit 20000. Then use `compare-blocked.js` and `compare-reason.js`. They take the window from the first accepted tab open after the last limit event.
- **Extension ID.** Pass the real ID to `send-extension-message-json.js`. `auto` works only for `open-dashboard.js` and `reload-chrome-dev.js`.
- **Ports.** The other browser is on 9223, so pass `--port 9223`. Killing Chrome by process name kills both browsers, so target by command line.
- **Background Chrome.** Chrome keeps running in the background after its last window closes. Close gracefully first.
- **Erase.** Send `erase-block-history` with confirmation `ERASE`. It pauses first, then clears every stored key, including settings and the paused flag, and reloads. Use a build that closes writes: 1584 and later do. The 1575 erase does not.
- **Waiting on runs.** Use a background sleep and wait for the completion notice. Don't block the foreground with long sleeps.
- **Before changing the worker or storage.** Read `entropy-reduction-action-plan-2026-09-09.md`, as `AGENTS.md` requires.
